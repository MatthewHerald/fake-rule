Fake Rule

One player knows the secret rule. Can you crack it?

or join a friend

How to play
  1. Each round, one player is the Rule Keeper and gets a secret rule, like "the answer has exactly 5 letters."
  2. Everyone gets a prompt, like "Name an animal," and types an answer. The Rule Keeper's answer always follows the rule.
  3. Answers are revealed with a ✓ if they follow the rule or an ✗ if they don't.
  4. Think you know the rule? Type a guess (one per prompt). The Rule Keeper decides if you're right.
  5. Scoring: +1 for each answer that follows the rule, +5 for cracking it. If nobody cracks it in 5 prompts, the Rule Keeper gets +4.
